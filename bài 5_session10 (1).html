Phần 1 . Xác định Input Output và sơ đồ phối hợp phần cứng của hệ thống trang trại

  • Input : Tín hiệu điện từ cảm biến độ ẩm đất và cảm biến nhiệt độ không khí , lệnh cấu hình thủ công từ người dùng qua giao diện.
  • Output : Trạng thái đóng mở của rơ-le máy bơm nước , bản ghi nhật ký dữ liệu trên màn hình hệ thống.

Phần 2 : File README.md hoàn chỉnh theo chuẩn kỹ sư phần mềm chuyên nghiệp.

Smart-Farm

Smart-Farm là hệ thống IoT giúp trang trại Lan theo dõi môi trường và tưới cây tự động.

Hướng dẫn cài đặt

sudo apt update
sudo apt install python3 -y
mkdir -p ~/Smart-Farm
cd ~/Smart-Farm

Tính năng

  • Đo nhiệt độ và độ ẩm.
  • Tự động tưới cây.
  • Cảnh báo môi trường bất thường.
  • Lưu nhật ký hoạt động.

Bảng thông số

  • Thông số
  • Giá trị mẫu
  • Nhiệt độ : 32°C
  • Độ ẩm đất : 35%
  • Ngưỡng tưới : 40%

Chu kỳ CPU

Fetch: Lấy lệnh từ RAM. Decode: Giải mã lệnh. Execute: Thực thi lệnh bật máy bơm.
